# 🌸 Mauli — Women's Safety Application

> **A mobile-based emergency safety application designed to provide quick access to help, location sharing, and emergency alerts.**

### 🛠️ Technologies Used

**Android Studio · Java · XML · Firebase · GPS**

---

## 📌 About the Project

**Mauli** is a women's safety application developed to provide quick and accessible assistance during emergency situations.

The application uses **GPS technology** to identify the user's location and enables them to quickly alert their trusted contacts during an emergency. By combining emergency messaging, helpline access, audio deterrence, and automated alerts, Mauli aims to provide users with a simple and reliable safety companion.

The application focuses on reducing the time required to seek help when a person is in a potentially unsafe or unfamiliar situation.

### 🎯 Key Objectives

* 📍 **Real-time Location:** Identify and share the user's location using GPS.
* 🚨 **Quick Emergency Alerts:** Send an alert to saved emergency contacts with minimal interaction.
* 📞 **Instant Helpline Access:** Provide quick access to important emergency helpline numbers.
* 🔊 **Siren Feature:** Play a police-siren sound to attract attention and potentially deter a threatening situation.
* 🎙️ **Audio Recording:** Start recording during an emergency to help preserve relevant information.
* 👥 **Emergency Contacts:** Allow users to add and manage trusted relatives or contacts.

## 🚨 One-Tap Emergency Alert

### All Emergency Features in One Click

The **Alert** feature combines multiple emergency actions into a single interaction.

When triggered, the application can:

* 🎙️ Start audio recording
* 🔊 Activate the siren
* 📍 Capture the user's location
* 📩 Send an emergency alert to saved contacts

This design minimizes the number of actions required during an emergency situation.
